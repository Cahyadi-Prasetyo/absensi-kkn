# Absensi KKN (Kuliah Kerja Nyata)

Sistem Informasi Absensi untuk program Kuliah Kerja Nyata (KKN).

## Struktur Branch
Repositori ini menggunakan alur kerja Git (Git Flow sederhana) dengan branch utama:
- `main` : Branch stabil untuk produksi/rilis.
- `dev` : Branch pengembangan aktif untuk integrasi fitur baru sebelum digabungkan ke `main`.
